# Roadmap

This is implementation order, not a delivery or token-return promise.

1. Validate real GPU inference through the pinned vLLM plugin, bridge, native verifier and contribution ledger.
2. Prepare and fund a closed testnet epoch, then verify a real wallet claim and transaction confirmation.
3. Improve contribution measurement, epoch operations, monitoring, backups and recovery.
4. Complete reward transaction status, mining analytics and public allocation records.
5. Publish tested worker images and simplify hardware/connectivity diagnostics.
6. Evaluate real managed GPU capacity and compute-package accounting.
7. Add inference products, model access, API keys and usage billing when actual serving capacity is ready.
8. Define and fund the mainnet mining reserve for the planned 1B PERL Pons launch.

Settlement remains on Robinhood. A new blockchain is outside this roadmap. Testnet balances have no automatic mainnet conversion.
